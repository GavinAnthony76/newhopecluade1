## 🎨 CUSTOMIZATION GUIDE

### Change Colors (2 minutes):
```css
/* Edit /css/variables.css */
:root {
  --color-primary: #your-blue;
  --color-accent: #your-gold;
}
```

### Change Fonts (2 minutes):
```css
/* Edit /css/variables.css */
:root {
  --font-heading: 'Your Font', serif;
  --font-body: 'Your Font', sans-serif;
}
```
